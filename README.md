# 📄 CV Web – Sebastian Mendoza

Página web personal desarrollada con **React + Vite**, diseñada para mostrar y permitir la visualización y descarga de mi hoja de vida en formato PDF.  
El proyecto presenta una interfaz **moderna, minimalista y profesional**, ideal para compartir en procesos académicos y laborales.

---

## 🚀 Tecnologías utilizadas

- ⚛️ **React** – Librería para interfaces de usuario
- ⚡ **Vite** – Entorno de desarrollo rápido
- 🎨 **CSS inline (JavaScript Styles)** – Estilización moderna
- 🌐 **Netlify** – Despliegue continuo
- 🗂️ **Git & GitHub** – Control de versiones

---

## 🎯 Objetivo del proyecto

- Centralizar mi hoja de vida en una URL pública
- Permitir **ver el CV en el navegador** sin descargar
- Ofrecer opción de **descarga directa en PDF**
- Aplicar buenas prácticas de desarrollo frontend y despliegue
